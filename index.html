Configuración de un Router TP-Link

Guía básica paso a paso

Introducción

Un router TP-Link permite conectar varios dispositivos a Internet mediante una red cableada o inalámbrica Wi-Fi.

Paso 1: Conectar el Router

  • Conecte el cable de Internet al puerto WAN del router.
  • Conecte una computadora al router mediante cable o Wi-Fi.
  • Encienda el equipo.

Paso 2: Entrar a la Configuración

Abra un navegador e ingrese una de estas direcciones:

  • 192.168.0.1
  • 192.168.1.1

Usuario y contraseña inicial:

  • Usuario: admin
  • Contraseña: admin

Paso 3: Configurar Internet

Seleccione el tipo de conexión de su proveedor de Internet:

  • IP Dinámica (DHCP)
  • PPPoE
  • IP Estática

Paso 4: Configurar Wi-Fi

  • Cambiar el nombre de la red Wi-Fi.
  • Crear una contraseña segura.
  • Usar seguridad WPA2 o WPA3.

Recomendaciones de Seguridad

  • Cambiar la contraseña del administrador.
  • Actualizar el firmware del router.
  • No compartir la clave Wi-Fi.
